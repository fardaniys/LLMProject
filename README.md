# LLMProject
This portfolio demonstrates advanced capability in evaluating Large Language Models (LLMs) and agent systems using structured, rubric-based methodologies aligned with real-world AI evaluation workflows (e.g., RLHF, benchmarking, and QA pipelines).

**Model**
I use the LLM model from Ollama (gpt-oss:120b-cloud)
Each case use same model but a different chat.

**Evaluation Framework**

**Core Rubric (0–5 Scale)**
Accuracy – Factual correctness
Clarity – Readability and communication quality
Logical Consistency – Coherent reasoning flow
Completeness – Coverage of the task
Instruction Adherence – Follows prompt constraints
Hallucination Risk – Unsupported claims or fabrication

**Additional Dimensions**
Reasoning Transparency – Are steps explicit?
Context Sensitivity – Handles ambiguity/conditions
Robustness – Stability across edge cases
